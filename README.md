# 🎬 Kino.watch Collection

> Умный юзерскрипт для **Tampermonkey**, который автоматически ищет IMDb-ссылку на странице фильма, определяет всю кинематографическую коллекцию/франшизу через TMDB API, находит каждый фильм на сайте Kino.watch, исключает 3D-версии и выводит удобные кнопки навигации с русскими названиями и подсветкой текущей страницы.

## ✨ Основные возможности

* **🔍 Автоматический поиск по IMDb:** Находит идентификатор фильма прямо на странице просмотра.
* **📦 Интеграция с TMDB API:** Самостоятельно запрашивает список всех связанных фильмов франшизы (коллекции).
* **🌐 Локализация названий:** Ищет фильмы на сайте по точным оригинальным (английским) названиям, а на кнопках выводит **русские названия** с годами релиза.
* **📅 Сортировка по годам:** Все части коллекции автоматически выстраиваются по хронологии (от ранних к поздним).
* **🎯 Подсветка текущего фильма:** Кнопка фильма, на странице которого вы сейчас находитесь, подсвечивается фирменным зелёным цветом интерфейса.
* **🚫 Фильтрация 3D:** Умный алгоритм парсинга результатов поиска отсекает дублирующие 3D-издания, оставляя только стандартные версии.
* **📺 Умное определение типа контента:** Скрипт автоматически срабатывает только для фильмов (`s0`), полностью игнорируя сериалы с сезонами (`s1`, `s2` и т.д.).
* **🛡️ Полная автономность:** Работает полностью внутри юзерскрипта (без необходимости держать собственный бэкенд-сервер).

## 📥 Быстрая установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера.
2. Нажмите на ссылку ниже для автоматической установки скрипта:

<div align="center">

👉 **[Установить Kino.watch Collection](https://kw.xlnt.ovh/collection.user.js)** 👈

</div>

3. Подтвердите установку во всплывающем окне Tampermonkey.
4. Откройте любой фильм на `kino.watch` и наслаждайтесь просмотром!

---

## 🛠️ Используемые технологии

* **JavaScript (Userscript / Tampermonkey API):** DOMParser, `GM_xmlhttpRequest` для кросс-доменных запросов.
* **The Movie Database (TMDB) API:** Получение информации о фильмах, сиквелах и коллекциях.
* **CSS Flexbox:** Адаптивная и стильная верстка блока под дизайн сайта.
